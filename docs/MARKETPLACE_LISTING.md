# GitHub Marketplace listing

## Listing name

Public Health Repo Auditor

## Short description

Automated reproducibility, documentation, privacy, and ethics checks for
public-health research repositories.

## Full description

Public Health Repo Auditor gives research teams a transparent repository
quality score on every push and pull request. It checks documentation,
licensing, citation metadata, dependencies, reproducibility commands, tests,
data dictionaries, provenance, privacy warnings, and ethics statements.

Each result appears as a GitHub Check Run with an explainable score,
file-level warnings, and links to remediation guidance. Repositories can set
their own threshold, required files, ignored paths, disabled checks, and
privacy terminology in `.ph-repo-auditor.yml`.

The score is decision support for maintainers. It does not certify scientific
validity, regulatory compliance, privacy compliance, or research ethics.
